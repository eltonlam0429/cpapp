# 我們 · 情侶網頁 App

只屬於兩個人的小空間。藍色液態玻璃風格，可以加到手機主畫面像 app 一樣用。

**功能**：主頁（兩人名字、在一起天數、連續記錄）、今日問題、螢幕便條（可附相片）、待辦事項、清單、願望清單、日曆（活動、重複、多天活動、紀念日、生日，每 100 天和每個週年自動標記，無上限）、經期記錄和推算、最近刪除（7 天內可還原）、下載和還原備份。

**同步**：資料存在你們自己的 Google 試算表。每部手機都有一份本機副本，沒有網絡也能用；有網絡時大約每 12 秒、以及每次打開 app 時自動同步。

---

## 第一步：設定 Google 試算表（約 5 分鐘）

1. 打開 [Google 試算表](https://sheets.new)，新增一個空白試算表，名字隨意（例如「我們」）。
2. 選單按 **擴充功能 → Apps Script**。
3. 把編輯器裏原本的內容全部刪掉，貼上 `google-apps-script/Code.gs` 的全部內容。
4. 把第 9 行的 `'改成你們自己的密碼'` 改成一個只有你們知道的密碼，例如 `'blue-sky-2025-xyz'`。
5. 按 💾 儲存。
6. 右上角按 **部署 → 新增部署作業**：
   - 齒輪圖示選 **網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按 **部署**，第一次會要求授權：選你的帳戶 → 「進階」→「前往（不安全）」→ 允許。這是因為腳本是你自己寫的，未經 Google 審核，屬正常。
7. 複製 **網頁應用程式網址**（以 `/exec` 結尾），稍後會用到。

> 之後如果要更新 Code.gs，請用 **部署 → 管理部署作業 → ✏️ 編輯 → 版本：新版本**，網址才會保持不變。

## 第二步：放上 GitHub Pages

1. 在 GitHub 新增一個 repository（例如 `us`）。
2. 把這個資料夾的**所有檔案**上傳到 repo 的根目錄，保持資料夾結構：
   ```
   index.html
   style.css
   manifest.webmanifest
   sw.js
   js/  (app.js, data.js, store.js, ui.js)
   icons/
   google-apps-script/Code.gs   ← 可以一起上傳，裏面沒有你的密碼
   ```
   最簡單的方法：在 repo 頁面按 **Add file → Upload files**，把整個資料夾的內容拖進去。
3. 到 repo 的 **Settings → Pages**：Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/(root)**，按 Save。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/us/`。

## 第三步：兩部手機開始用

**第一個人：**
1. 用手機 Safari（或 Chrome）打開上面的網址，填兩個人的名字，按「開始」。
2. 到 **個人檔案 → 雲端同步**，貼上第一步的 `/exec` 網址和密碼，按「儲存並同步」。
3. 按 **個人檔案 → 邀請你的另一半**，把連結傳給對方。

**第二個人：**
1. 用手機打開收到的連結，揀「我是 ○○」，就完成了，不用再填網址和密碼。

**加到主畫面：** iPhone 在 Safari 按分享 → **加入主畫面**；Android 在 Chrome 選單 → **加到主畫面**。

## 常見問題

**兩個人都可以改名字嗎？** 可以。個人檔案 → 我們的名字，任何一方都可以改兩個人的名字，另一部手機會同步更新。如果揀錯了身分，按「我其實是另一位」就可以對調。

**資料在哪裏？** 在你自己 Google Drive 的試算表 `data` 工作表裏。每一行是一筆資料，不要手動改動那個工作表。

**怎樣備份？** 試算表本身就是一份備份。另外可以在 個人檔案 → 下載備份，得到一個 `.json` 檔，之後用「從備份還原」放回去。

**換手機或清除了瀏覽器資料？** 再用邀請連結打開一次，揀回自己的身分，資料會從試算表下載回來。

**密碼外洩了？** 在 Apps Script 改一個新的 `SPACE_KEY`，用「管理部署作業」發佈新版本，然後兩部手機在 雲端同步 填新密碼（或者重新傳邀請連結）。

**同步失敗：網址好像不對？** 確認貼的是「網頁應用程式」網址（`/exec` 結尾），而且部署時「誰可以存取」選了「所有人」。

**相片太大？** 相片會自動壓縮。試算表每筆資料上限約 900KB，一般手機相片壓縮後只有約 100KB。
